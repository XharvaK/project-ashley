# Ashley Hierarchy
```

```
Every decision in the Ashley project derives its authority from a higher layer.
```

```
Lower layers should implement higher layers.
```

```
Higher layers should not be modified merely to accommodate lower-layer
implementation details.
```

```
If a contradiction exists, it should be resolved by questioning the lower layer
first.
```

```
This hierarchy exists to prevent prompt drift, architectural inconsistency and
gradual erosion of Ashley's identity.
```

```
