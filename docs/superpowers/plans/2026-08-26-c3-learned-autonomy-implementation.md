# C3 Learned Autonomy Implementation Plan

## Goal

Implement the frozen C3 first qualified learned-interest witness on the C2
commit. A learned influence must change a later Curiosity ranking or Agency
motivation admission for a traceable reason, remain inside existing authority,
respect C1 correction/barrier eligibility, preserve lineage distinctions, and
be demotable without rewriting Identity.

## Constraints

- C3 first-wave kind is `interest` only.
- C3 consumes C1 assertions; it does not redesign C1.
- `observe` records proposals but cannot alter later choices.
- `dark_apply` is fixture-only and never grants live capability authority.
- `apply`, promotion, provider calls, Mint, deployment, qualification, and
  external effects are excluded.
- No shared-culture table, similarity score, universal belief graph, or
  Identity mutation.

## Implementation order

1. Add green characterization and focused C3 tests.
2. Add additive schema v37 and fail-closed schema validation.
3. Add typed admission, explicit adjudication, C1-aware eligibility, lineage
   projection, and metadata-only choice receipts.
4. Add dark-apply Curiosity ranking and Agency motivation admission with
   synchronous stale-candidate revalidation.
5. Add correction/demotion/rollback and owner diagnostics witnesses.
6. Run the consolidated C3-focused pack, the agent-service build, and
   `git diff --check`.
7. Write `docs/handoffs/C3_LOCAL_SETTLEMENT.md` and commit one coherent C3
   change.
